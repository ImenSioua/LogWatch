# LogWatch

Application de monitoring et d'analyse de logs avec Stack ELK, MongoDB, Redis
et interface web Flask (scénario D : application SaaS).

## Démarrage
1. Copier `.env.example` en `.env` et remplir les valeurs.
2. Lancer : `docker compose up`

## Structure
- `docs/` : documents d'analyse et d'architecture
- `figures/` : diagrammes et maquettes
